# Academia Online

Proyecto académico de una página web para una academia online, desarrollado para practicar HTML y CSS.

## Ver la web

[Visitar Academia Online](https://javiegomez.github.io/Pagina-Web---Proyecto-HTML/)

## Contenido

La web incluye páginas y secciones de:

- Inicio
- Cursos
- Noticias y blog
- Quiénes somos
- Contacto
- Registro e inicio de sesión
- Aviso legal

## Tecnologías utilizadas

- HTML5
- CSS3

## Proyecto

Este sitio se ha creado como práctica de desarrollo web. Los formularios son demostrativos y no envían datos a un servidor.
